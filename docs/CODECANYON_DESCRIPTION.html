🏥 Insight Health Pro – Complete Hospital Management System

Built with React 18, TypeScript, Supabase, and Tailwind CSS

Insight Health Pro is a comprehensive, production-ready Hospital Management System (HMS) designed for clinics, hospitals, and healthcare organizations of all sizes. It features 20+ integrated modules, role-based dashboards, real-time queue management, and AI-powered clinical tools — all in a single, self-contained package.

🔥 Key Highlights

  • ✅ 6 Role-Based Dashboards – Admin, Doctor, Nurse, Pharmacist, Receptionist, Lab Technician
  • ✅ Patient Management – Registration, records, ID cards, QR verification
  • ✅ Appointment Scheduling – Calendar view, waitlist, smart scheduling
  • ✅ Real-Time Queue System – Token-based, live status, patient check-in
  • ✅ Electronic Medical Records – Visit history, diagnosis codes (ICD-10), FHIR export
  • ✅ Prescription Management – Drug interactions, templates, refill workflow
  • ✅ Lab Test Management – Report generation, QR verification, trending
  • ✅ Blood Bank – Inventory, donors, transfusion records, compatibility checks
  • ✅ Operation Theatre – Surgery scheduling, teams, consent forms, post-op
  • ✅ IPD Management – Admissions, ward rounds, discharge summaries
  • ✅ Pharmacy & Inventory – Stock management, purchase orders, suppliers
  • ✅ Billing & Insurance – Payments, insurance claims, ICD/CPT coding
  • ✅ Doctor-Patient Messaging – Secure two-way communication
  • ✅ Staff Management – Schedules, departments, shift handovers
  • ✅ Notification System – Real-time alerts, email notifications
  • ✅ Reports & Analytics – Revenue, patient flow, staff performance
  • ✅ AI Clinical Copilot – AI-powered diagnosis suggestions
  • ✅ Patient Portal – Self-service appointments, records, symptom checker
  • ✅ Multi-language Support – English, Spanish, French, Arabic, Hindi, Urdu
  • ✅ Dark/Light Mode – Full theme support
  • ✅ PWA Ready – Installable on mobile devices
  • ✅ HIPAA Compliant – Audit logging, RLS policies, PHI tracking

⚡ Quick Start

  1. Clone the repository
  2. Run npm install
  3. Configure .env with your Supabase credentials
  4. Execute the database schema in Supabase SQL Editor
  5. Run npm run dev
  6. Login with demo credentials and seed sample data

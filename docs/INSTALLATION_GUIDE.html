2. Installation Steps

Quick Start (5 Minutes)

1

Extract Source Code

Extract the source-code folder from the ZIP archive to your desired location.

2

Install Dependencies

cd insight-health-pro
npm install
3

Create Environment File

cp .env.example .env

Edit .env and fill in your Supabase credentials (see Section 4).

4

Set Up Database

Execute the SQL schema file in your Supabase SQL Editor (see Section 3).

5

Start Development Server

npm run dev

Open http://localhost:5173 in your browser.

6

Login & Seed Demo Data

Use the demo credentials (Section 7) to log in, then click "Seed Demo Data" on the Admin Dashboard.

✅ Done!

Your hospital management system is now running locally with full functionality.

3. Database Setup

Step 1: Create a Supabase Project

  1. Go to supabase.com and sign in
  2. Click "New Project"
  3. Set a project name (e.g., insight-health-pro) and generate a strong database password
  4. Select the region closest to your users
  5. Wait ~2 minutes for provisioning

Step 2: Get API Credentials

  1. Go to Project Settings → API
  2. Copy the Project URL (e.g., https://xxxxx.supabase.co)
  3. Copy the anon public key (starts with eyJ...)

Step 3: Execute Schema

  1. Go to SQL Editor in Supabase dashboard
  2. Click "New Query"
  3. Open documentation/DATABASE_SCHEMA.sql from the package
  4. Paste the entire contents and click "Run"

Step 4: Verify

SELECT COUNT(*) as table_count 
FROM information_schema.tables 
WHERE table_schema = 'public';
-- Expected: 47+ tables

6. Admin Login Credentials

⚠️ Important: Creating Your Admin Account

For security, there are no default admin accounts. Follow these steps to create one.

1

Register a New Account

Navigate to /login → Click "Sign Up" → Register with your email and password.

2

Promote to Admin

Run this SQL in the Supabase SQL Editor:

UPDATE public.user_roles 
SET role = 'admin' 
WHERE user_id = (
  SELECT id FROM auth.users 
  WHERE email = 'your-admin@email.com'
);
3

Verify Access

Log out and log back in. You should now see the full Admin Dashboard.

10. Production Deployment

Build for Production

npm run build

This generates optimized static files in the dist/ folder.

Option A: Vercel (Recommended)

  1. Import your repository on vercel.com
  2. Set Framework Preset to Vite
  3. Add environment variables in Project Settings
  4. Deploy — automatic CI/CD on every push

Option B: Netlify

  1. Connect repository on netlify.com
  2. Build command: npm run build | Publish directory: dist
  3. Add environment variables and deploy

Option C: Static Server (Nginx / Apache)

# Build the application
npm run build

# Copy dist/ contents to your web server root
cp -r dist/* /var/www/html/

# Nginx: Add SPA routing rule
# location / { try_files $uri /index.html; }

11. Troubleshooting

IssueSolution
RLS policy error / permission deniedVerify user role in user_roles table. Re-run schema.sql if policies are missing.
Authentication error / Invalid JWTCheck VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY are correct.
Edge function 500 errorRun supabase secrets list to verify secrets. Check logs with supabase functions logs.
Database connection timeoutCheck if Supabase project is paused (free tier). Click "Restore" in dashboard.
Module not found errorsDelete node_modules and run npm install again.
Blank page after buildEnsure your server has SPA routing (all paths → index.html).

12. Security & Compliance

  • ✓ Row Level Security (RLS) — Enforced on all 55+ database tables
  • ✓ Role-Based Access Control — 6 distinct roles with granular permissions
  • ✓ PHI Audit Logging — All sensitive data access is logged for HIPAA compliance
  • ✓ No Hardcoded Credentials — All secrets via environment variables
  • ✓ SQL Injection Protection — Parameterized queries via Supabase SDK
  • ✓ XSS Protection — React DOM escaping, no dangerouslySetInnerHTML
  • ✓ JWT Authentication — Secure token-based sessions
  • ✓ Data Encryption — Encrypted at rest (Supabase PostgreSQL)
  • ✓ QR Code Verification — Tamper-proof verification for prescriptions, lab reports, patient IDs
